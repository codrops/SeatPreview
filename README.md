# Cinema Seat Preview Experiment

An experimental demo where a 3D perspective preview is shown for a selected seat in a cinema room.

![Featured Image Cinema Seat Preview](https://tympanus.net/codrops/wp-content/uploads/2016/01/CinemaSeatPreviewExperiment.jpg)

[Article on Codrops](https://tympanus.net/codrops/?p=25885)

[Demo](https://tympanus.net/Development/SeatPreview/)

Check out the version by Sebastian Troć where the real seats are colored, too: [SebastianTroc/SeatPreview](https://github.com/SebastianTroc/SeatPreview)

## Installation

Run this demo on a [local server](https://developer.mozilla.org/en-US/docs/Learn/Common_questions/Tools_and_setup/set_up_a_local_testing_server).

The styles in `css/component.css` are compiled from `css/component.scss` with [Dart Sass](https://sass-lang.com/dart-sass/):

```bash
npx sass css/component.scss css/component.css
```
